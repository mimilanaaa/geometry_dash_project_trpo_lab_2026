## Интерфейс (UI)

Демо интерфейса: главное меню → загрузка трека → выбор формы → экран с HUD → пауза, смерть, уровень пройден.

```
python3 -m ui.demo
```

| Файл | Что внутри |
| --- | --- |
| `ui/theme.py` | Темы Swiss (светлая, красный акцент) и Noir (тёмная, золотой акцент), цвета форм |
| `ui/form_view.py` | Отрисовка форм: куб — оранжевый, корабль — синий, шар — красный, волна — бирюзовая, НЛО — фиолетовое |
| `ui/hud.py` | HUD: полоска прогресса, процент, лучший результат, попытка, текущая форма |
| `ui/menu.py` | Меню выбора формы; в первой версии открыты куб и корабль |
| `ui/track_screen.py` | Экран загрузки трека: выбор файла, сложность (лёгкий/обычный/сложный), генерация уровня через `generator/level_builder.py`, кнопки «Ещё вариант», «Карта» и «Играть» |
| `ui/object_view.py` | Отрисовка препятствий (шип, блок, орб, батут) и порталов; портал окрашен в цвет формы, в которую превращает |
| `ui/screens.py` | Главное меню, пауза, экран смерти, «Уровень пройден», настройки |
| `ui/settings.py` | Сохранение темы и громкости в `~/.musically_geometry/settings.json` |
| `ui/level_viewer.py` | Просмотр уровня из JSON (формат `generator/level_format.py`) с сеткой битов |
| `ui/demo.py` | Демо-запуск всех экранов |

Клавиша T переключает тему на любом экране.

## Просмотр уровня

```
python3 -m ui.level_viewer levels/my_level.json
```

Без пути открывается встроенный демо-уровень. Стрелки — прокрутка, + и − — масштаб, Home — в начало.

## Общие настройки (`config.py`)

Все числа, которые должны совпадать у генератора, физики и интерфейса, лежат в одном файле `config.py` в корне проекта. Если менять значение, то только там.

| Константа | Значение | Кто использует |
| --- | --- | --- |
| `SCROLL_SPEED` | 500 пикс/с | генератор (x = время × скорость), физика (движение уровня) |
| `FLOOR_Y` / `CEILING_Y` | 100 / 600 | генератор, физика, отрисовка |
| `OBJECT_SIZE` / `PLAYER_SIZE` | 50 | коллизии, отрисовка |
| `MIN_SAFE_GAP` | 0.45 с | генератор: минимальный промежуток между препятствиями |
| `CUBE_JUMP_HEIGHT` / `CUBE_AIR_TIME` | 110 пикс / 0.38 с | физика куба; `CUBE_GRAVITY` и `CUBE_JUMP_SPEED` считаются из них |
| `SHIP_GRAVITY` / `SHIP_THRUST` | 1800 / 3600 | физика корабля |
| `DIFFICULTY_STEPS` | easy 4, normal 2, hard 1 | генератор: препятствие на каждом N-м бите |

Пример для физики куба:

```
from config import CUBE_GRAVITY, CUBE_JUMP_SPEED, FLOOR_Y

vy = CUBE_JUMP_SPEED
vy -= CUBE_GRAVITY * dt
y += vy * dt
```

## Тесты

```
python -m pytest tests
```

`tests/test_config.py` проверяет, что числа в `config.py` совместимы: куб перепрыгивает шип и приземляется раньше следующего препятствия, кораблю хватает места между полом и потолком.
