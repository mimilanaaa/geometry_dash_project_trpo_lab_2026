## Установка

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Интерфейс (UI)

Демо интерфейса: главное меню → загрузка трека → выбор формы → экран с HUD → пауза, смерть, уровень пройден.

```
python3 -m ui.demo
```

| Файл | Что внутри |
| --- | --- |
| `ui/theme.py` | Темы Swiss (светлая, красный акцент) и Noir (тёмная, золотой акцент), цвета форм |
| `ui/form_view.py` | Отрисовка форм: куб — оранжевый, корабль — синий, шар — красный, волна — бирюзовая, НЛО — фиолетовое |
| `ui/hud.py` | HUD: полоска прогресса, процент, лучший результат, попытка, текущая форма |
| `ui/menu.py` | Меню выбора формы; в первой версии открыты куб и корабль |
| `ui/track_screen.py` | Экран загрузки трека: выбор файла, проверка формата и длительности, анализ через `music/beat_detect.py` |
| `ui/object_view.py` | Отрисовка препятствий (шип, блок, орб, батут) и порталов; портал окрашен в цвет формы, в которую превращает |
| `ui/screens.py` | Главное меню, пауза, экран смерти, «Уровень пройден», настройки |
| `ui/settings.py` | Сохранение темы и громкости в `~/.musically_geometry/settings.json` |
| `ui/level_viewer.py` | Просмотр уровня из JSON (формат `generator/level_format.py`) с сеткой битов |
| `ui/demo.py` | Демо-запуск всех экранов |

Клавиша T переключает тему на любом экране.

## Просмотр уровня

```
python3 -m ui.level_viewer levels/my_level.json
```

Без пути открывается встроенный демо-уровень. Стрелки — прокрутка, + и − — масштаб, Home — в начало.
